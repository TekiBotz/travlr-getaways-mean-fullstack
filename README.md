# cs465-fullstack
CS-465 Full Stack Development with MEAN

Architecture
In this project two primary types of front-end development were used: traditional server-side rendering with Express HTML/JavaScript and a client-side rendered single-page application (SPA) with Angular. Express HTML/JavaScript was used initially to create static pages directly from the server. On the other hand, the Angular SPA offered rich, interactive features with faster page loads after the initial load. The backend utilized a NoSQL MongoDB database due to its flexibility in handling unstructured data, scalability, and ease of integration with JavaScript-based technologies, making it ideal for the MEAN stack.

Functionality
JSON was used to facilitate the transmission of structured data between the server and the client, playing a crucial role in full stack development. Throughout this project, code refactoring was performed to improve functionality and efficiency, such as creating reusable UI components for easier updates, consistent design, and faster development.

Testing
Testing the full stack application involved methods like unit testing, integration testing, and end-to-end testing for API endpoints using software such as Postman. Security testing also ensured that only authorized users can access endpoints and data is transmitted securely using authentication mechanisms like JWT. This is crucial for building robust and secure software that protects sensitive data.
